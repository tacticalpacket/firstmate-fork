# Evidence: output shape unchanged, and the regression test has teeth

## A. The emitted JSON is byte-identical wherever the old transport worked

The old argv transport dies above the kernel's 131072-byte single-argument
limit. At every backlog size it could still carry, the new stdin transport
emits exactly the same bytes (cmp, not a shape comparison):

    1-row backlog ->   4038 bytes   cmp: identical
   25-row backlog ->  34753 bytes   cmp: identical
   60-row backlog ->  79553 bytes   cmp: identical
   80-row backlog -> 105153 bytes   cmp: identical
   90-row backlog -> 117953 bytes   cmp: identical
   95-row backlog -> 124353 bytes   cmp: identical
  120-row backlog -> pre-fix emits 0 bytes (argv limit); post-fix emits the
                     whole document. That difference is the fix.
